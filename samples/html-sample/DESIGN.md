# Design direction

Reading this as: an editorial personal-care mobile product for thoughtful home gardeners, with a calm botanical language, leaning toward native CSS and an original field-notes interface.

Design variance: 6. Motion: 3. Density: 4.

The visual system uses ink-blue, cool paper and one moss accent. Botanical forms are constructed from CSS rather than stock photography so the sample remains portable. Large editorial numbers establish pace; ruled lines, soft corners and plant silhouettes keep screens connected without turning them into a generic card grid.

Interactive affordances use accessible contrast, visible keyboard focus, pressed states and reduced-motion support. Each page contains a useful state, including the journal's intentional empty state.
